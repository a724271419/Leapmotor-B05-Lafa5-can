# E2E 校验与 seed 表（2026-11-05 定稿）

> 来源：QNX 二进制 `lpAdasInput` / `lpIcuGw` / `lpCanEngine` 的符号与反汇编（未剥符号），
> 以及 57,077 帧实车数据的独立反推；两条路径互证。

## 算法

```
byte0 = CRC8_H2F( data[1..len-1] || seed[counter] )
counter = data[1] & 0x0F
poly 0x2F / init 0xFF / xorout 0xFF / 不反射
```

C 参考实现：

```c
uint8_t crc8_h2f(const uint8_t *p, size_t n, uint8_t seed) {
  uint8_t crc = 0xFF;
  for (size_t i = 0; i < n; i++) {
    crc ^= p[i];
    for (int k = 0; k < 8; k++) crc = (crc & 0x80) ? (uint8_t)((crc << 1) ^ 0x2F) : (uint8_t)(crc << 1);
  }
  crc ^= seed;
  for (int k = 0; k < 8; k++) crc = (crc & 0x80) ? (uint8_t)((crc << 1) ^ 0x2F) : (uint8_t)(crc << 1);
  return crc ^ 0xFF;
}
```

## 用法

构造一帧 0x083：

```
b[0] = 0;                       // 占位
b[1] = (counter << 0) | ...;    // 低 4 位是 counter，其余是载荷
...                             // 填 b[2..31]
b[0] = crc8_h2f(b + 1, 31, S[b[1] & 0x0F]);
```
