## 1. 一页结论

### 已解决

| 领域 | 结论 |
|---|---|
| OTA 解密 | AES-256-GCM，1 MiB 分块，key/iv 取自清单 `aes` 字段；13/13 文件通过认证 |
| 包结构 | ICHS 22 子镜像；FSC 相机 13 成员；TBOX 五卷 UBI |
| 车辆配置 | 从 QNX 拉回 107 个配置文件（7.2 MB），含 527 条信号目录与 ID→通道映射 |
| 0x18D 布局 | **32 字节版三源闭环**（DWARF 布局 + 反汇编语义 + literal pool 缩放） |
| CAN 拓扑 | 11 条总线、8 个通道组、CCAN 物理成员与针脚已定 |
| 本车配置 | 单目摄像头 FSC + 域控 + 超声波 + 环视；**无前雷达、无 BSD 雷达** |
| 横向控制 | 0x083 指令 → 0x18D 执行反馈，`raw×0.02 − 650`（DBC 权威），指令/反馈中位差 0.000° |
| 转向灯 | `0x290 b2` 四态（1F/3F/5F/9F = 关/左/右/双闪）；b3 仅为 1.25 Hz 灯输出 |
| 拨杆 | **分级启动**：下拨1次=ACC、连续再下拨=LCC、上拨=全退（见 09 C1） |
| FuncMode | 1=刹车全退、2=上拨全退、3=在控、**5=LCC 单退且 ACC 保留**（扭矩/打灯/线丢失） |
| 设定速度 | `0x083 b5.5–b6.7` × 0.1 km/h；仪表读数比 CAN 高 ≈4.6%（不校正）；**语义待确认**（驾驶员设定 vs 跟车目标，见 09 B12/U12） |
| CarState 管线 | ndjson → 50 Hz → CarState JSON 影子；11/11 夹具、6 包 0 硬不变式；`aEgo` 与 `aEgoRobust` 双口径 |

### 三条软路径全部关闭（同一根因：缺平台签名）

| 路径 | 阻塞点 |
|---|---|
| CarService 读车辆属性 | `CAR_INFO` 是 `signature\|privileged`，自签证书拿不到 |
| DDS/`lpcom` 订阅 CAN 桥 | SELinux 拒绝 `ioctl 0x8927`（SIOCGIFHWADDR），`untrusted_app` 域做不了 DDS 发现 |
| 安装工具重签 | 「安全安装中心」只做 ADB 安装，不重签 |

### 唯一确定可行路线

**CAN-FD 采集器 + EL231-7/17 被动抓包。**

## 2. 安全红线（必须遵守）

1. **不得伪造/重签 OTA 包**，不得绕过安全启动链（清单 sign + otaCert + AVB + SWUpdate sha256）
2. **不得向车内网络/总线注入报文**，不得做诊断写入（UDS 0x2E/0x31/0x2F 等）
3. **DDS 只允许订阅**，绝不向 `/leap/hpc/public/p/lpGateway`（HMI→车身控制 topic）等控制 topic 发布任何内容
4. **禁止删除 `/opt/fota/` 下任何文件**（升级工作区，删了可能进入半升级状态）
5. **不得点击**工程控制台的「升级」「OTA循环升级」「ECU循环升级」「重置所有控制器」「工厂模式」
6. CCAN 只做**高阻并联监听**：采集器关闭内置 120Ω（原车已有 60Ω），支线 ≤10 cm，双绞
7. 禁止短路 CAN-H/L；禁止带电插拔
8. **不要对 `com.leapmotor.systemupdate` 执行 `am force-stop`** —— 会破坏 App↔QNX 会话，之后所有 `-101` 请求返回 `-150`，需重启车机才恢复（见 `04_failures_gotchas.md`）

## 3. 快速开始

### 3.1 车机在线时

```powershell
$adb='C:\Users\<user>\AppData\Local\Android\Sdk\platform-tools\adb.exe'
$s='192.168.100.122:5555'
& $adb connect $s
& $adb -s $s shell "getprop ro.product.cpu.abilist"      # 确认含 armeabi-v7a
& $adb -s $s shell "ls -l /system/lib/liblpComPSJNI.so"  # 265608 字节
```

### 3.2 抓包（硬件到位后）

```
接点：EL231-7 (CANH, 红黑) / EL231-17 (CANL, 蓝黑)
先量 7↔17 电阻 ≈ 60Ω，再上电
采集器：CAN-FD，仲裁 500k / 数据 2M，ISO，BRS 开，**监听模式**，**关闭内置终端**
```

详细参数与降级梯度见 `03_flows_findings.md` §5。

### 3.3 跑探针（现有产物）

```powershell
& $adb -s $s install -r G:\Codex\lpcom-probe2\app-signed.apk   # 已装过则覆盖可绕过白名单
& $adb -s $s shell "logcat -c; am start -n com.probe.lpcom2/.MainActivity"
& $adb -s $s shell "logcat -d -s LpComProbe5 | tail -20"
```
